Язык разметки, вдохновлённый вики-разметкой MediaWiki и языком Markdown. Компилируется в HTML.
## О языке
Данный язык я (Antarktidov) сделал, чтобы вести что-то вроде личных заметок. Взял то, что больше всего мне нравится в Markdown и Вики-разметке. И то, что смог, то и реализовал. Не судите строго, первый языке всё-таки. Но замечания и предложения по улучшению (если вы пользователь) и советы (если вы опытный разработчик языков) оставляйте в разделе [issues](https://github.com/Antarktidov/Antarktidov-Markup-Language/issues).

## Начало работы
**Актуально для версии [alpha-1.1.1](https://github.com/Antarktidov/Antarktidov-Markup-Language/releases/tag/alpha-1.1.1)**

Скачать язык можно со страницы [releases](https://github.com/Antarktidov/Antarktidov-Markup-Language/releases). Просто скачиваете exe-шник и всё. Чтобы можно было вызвать язык из любого места, нужно добавить путь к нему в переменную PATH. О том, как это сделать, см. на сайте [remontka.pro](https://remontka.pro/add-to-path-variable-windows/).
После добавления нужно в папке, где вы будете работать с языком, создать файл ``.env``.
Пример содержимого:
```env
domain=http://localhost
title=Заголовок
html_lang=ru
```
Теперь давайте создадим наш первый файл: ``hello.aml``
```markdown
# Hello
Привет, aml!
```
А теперь запустим команду:
```cmd
aml hello.aml hello.html
```
У нас получился html-файл*:
```html
<h1>Hello</h1>
<p>Привет, aml</p>
```

\* Здесь и далее показано только содержимое тэга body, если не указано иное, а сам html отформатирован, чтобы выглядеть человеко-читаемым.

## Синтаксис
**Актуально для версии [alpha-1.1.1](https://github.com/Antarktidov/Antarktidov-Markup-Language/releases/tag/alpha-1.1.1)**

### Заголовки
Язык поддерживает заголовки как в Markdown:
```markdown
# Заголовок 1
## Заголовок 2
### Заголовок 3
#### Заголовок 4
##### Заголовок 5
###### Заголовок 6
```
как в вики-разметке:
```wikitext
= Заголовок 1 =
== Заголовок 2 ==
=== Заголовок 3 ===
==== Заголовок 4 ====
===== Заголовок 5 =====
====== Заголовок 6 ======
```
А также обычные html-заголовки:

> Тут баг

### Базовые элементы абзаца
```wikitext
[[Вики-ссылка]], [[Вики-ссылка|Отображаемый текст]], [[Файл:Изображение.png]] [[Файл:Изображение с указанием ширины.png|200]]
```
```markdown
[Текст внешней ссылки](https://example.com/) !(https://example.com/картинка.png) !(https://example.com/картинка-с-указанием-ширины.png)[200]
```
### Галерея
Данный язык поддерживает галереи, как в MediaWiki (ограничено):
```wikitext
<gallery>
image1.png|Картинка 1
image2.png|Картинка 2
image3.png|Картинка 3
</gallery>
```
### Шаблоны
```wikitext
{{Обновить}}
```
Найдёт шаблон Обновить.taml в папке ``templates``, скомпилирует его в html (папка ``templates-html``) и вставит скомпилированный текст в общий html.
> [!WARNING]  
> Работают только шаблоны, стоящие на отдельной строке. Разметка вида:
```
Lorem {{Обновить}} ipsun
```
> [!WARNING]  
> Работать не будет!

> [!WARNING]  
> Параметры шаблонов, в отличие от вики-разметки не поддерживаются.
### Инфобоксы
Синтаксис инфобоксов похож на синтаксис инфобоксов MediaWiki, но отличается:
```wikitext
{{Инфобокс:
Title=AML|
Изображение=Aml.png|
Разрабочик=Antarktidov|
Язык программирования=Rust
}}
```
Инфобокс поддерживает маркированные списки:
```wikitext
{{Инфобокс:
Title=AML|
Изображение=Aml.png|
Разрабочик=Antarktidov|
Язык программирования=Rust|
Вдохновлён=
* Markdown
* Wikitext
}}
```
Поле Изображение поддерживает тег ``<gallery>``:
```wikitext
{{Инфобокс:
Изображение=<gallery>
image1.png|12
image2.png|23
</gallery>
|Test=Test field
}}
```
> [!WARNING]  
> Возможны баги

### Блоки кода
Язык поддерживает блоки кода, как в Markdown
```markdown
```python
print("Hello, world!")
```/
```
Примечание: символ / тут лишний.
### Div-элементы
Разработчик позаботился, чтобы язык поддерживал обычные div-элементы:
```html
<div class="test" style="padding: 1rem; border: 2px solid red; border-radius: 12px">
Aml написан с использованием следующих языков:
* Rust
* Css
* Js
* Html
</div>
```
Результат:
```html
<div class="test" style="padding: 1rem; border: 2px solid red; border-radius: 12px">
    <p>Aml написан с использованием следующих языков:</p>
    <ul>
        <li>Rust</li>
        <li>Css</li>
        <li>Js</li>
        <li>Html</li>
    </ul>
</div>
```
> [!WARNING]  
> Для корректной компиляции открывающий и закрывающий div должны быть в начале строки и занимать всю строку.
### Таблицы
Язык поддерживает markdown-таблицы:
```markdown
| 1  | 2  | 3  | 4  | 5  |
|----|----|----|----|----|
| 11 | 12 | 13 | 14 | 15 |
| 21 | 22 | 23 | 24 | 25 |
| 31 | 32 | 33 | 34 | 35 |
```
И вики-таблицы (частично, ограниченно):
```wikitext
{| class="wikitable"
!colspan="6"! Shopping List
|-
|rowspan="2"| Bread & Butter
| Pie
| Buns
| Danish
|colspan="2"| Croissant
|-
| Cheese
|colspan="2"| Ice cream
| Butter
| Yogurt
|}
```
Внутри таблиц частично поддерживается разметка (поддерживается всё, что в пункте «Базовые элементы абзаца»).
## CSS и JS
**Актуально для версии [alpha-1.1.1](https://github.com/Antarktidov/Antarktidov-Markup-Language/releases/tag/alpha-1.1.1)**

Страницы можно кастомизировать через css и js. Для этого подключите нужные страницы файле ``.env``:
```env
domain=http://localhost
title=Заголовок
html_lang=ru
css="stylefile"
js="script"
```
или:
```env
domain=http://localhost
title=Заголовок
html_lang=ru
css="stylefile,stylefile2"
js="script1,script2,script3"
```
